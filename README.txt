NNC — Tarek El Molla bilingual contact website

Files:
- index.html: bilingual contact page
- styles.css: responsive styling
- assets/nnc-logo.png: company logo
- contact.vcf: contact download

FREE PUBLISHING WITH GITHUB PAGES
1. Sign in at https://github.com/
2. Create a public repository named nnc-tarek-contact.
3. Upload all contents of this folder; index.html must be at repository root.
4. Go to Settings > Pages.
5. Under Build and deployment select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the published URL. It should look like:
   https://YOUR-USERNAME.github.io/nnc-tarek-contact/

FINAL QR
The final QR must be generated only after the site is published, using the exact URL above with your actual username. Edit make_qr.py and replace YOUR-USERNAME, then run python make_qr.py.
